# سكرتاري | Secretary

> تطبيق ويب شخصي لإدارة **اليوم والأسبوع والشهر**، فصل **الحياة الخاصة عن العمل**، تذكيرك بمهامك
> **في وقتها** (صوتاً ومرئياً)، وقراءة ملاحظاتك **بصوت مسموع**، مع **مخطط للخطط التي تنتهي صلاحيتها
> ويُجدَّد تلقائياً**.

الموقع **ثابت بالكامل** (HTML/CSS/JS بدون أي خادم أو قاعدة بيانات خارجية)، ويعمل **دون اتصال**،
ويُثبَّت على الهاتف والحاسوب كتطبيق (PWA).

---

## التشغيل

| الطريقة | الخطوات |
|---|---|
| **فتح مباشر** | افتح `secretary/index.html` في Chrome / Edge |
| **خادم محلي** | `powershell -File secretary/tools/serve.ps1` ثم افتح `http://localhost:8899/secretary/` |
| **النشر** | ارفع مجلد `secretary/` كما هو على GitHub Pages / Netlify / أي استضافة ثابتة |

> يُفضَّل التشغيل عبر `http://` أو `https://` للحصول على Service Worker (العمل دون اتصال) وإشعارات المتصفح.

## المزايا

### 1. الحسابات والخصوصية (عزل كامل لكل مستخدم)
- تسجيل دخول/إنشاء حساب **بالبريد الإلكتروني وكلمة مرور**.
- كلمات المرور تُخزَّن **مُجزّأة (SHA‑256 + salt لكل مستخدم)** — لا تُحفظ كنص صريح.
- كل مستخدم له **مساحة تخزين منفصلة تماماً** داخل `localStorage`:
  `secretary:v1:u:<userId>` — ولا يستطيع أي مستخدم آخر قراءة أو تعديل بياناتك.
- **حارس ملكية** يمنع أي كتابة داخل مساحة مستخدم آخر حتى عبر التلاعب البرمجي.

#### الدخول والخروج (محسّن)
| الميزة | التفاصيل |
|---|---|
| **«تذكرني» فعّال فعلاً** |checked→ الجلسة في `localStorage` (تنتهي بعد 30 يوم) • unchecked→ الجلسة في `sessionStorage` (تنتهي بإغلاق المتصفح) |
| **شاشة قفل مستقلة** | ببساطة، صورة رمزية، حقل كلمة المرور، «فتح التطبيق»، و«تسجيل الخروج بدلاً من ذلك» |
| **قفل تلقائي** | عند عدم النشاط (15 دقيقة) + زر قفل فوري من الشريط الجانبي والإعدادات وقائمة الحساب |
| **قائمة الحساب** (أيقونة الصورة في الأعلى) | الملف الشخصي • قفل التطبيق • الإعدادات • تسجيل الخروج • **خروج من كل الأجهزة** |
| **معلومات الجلسة** | نوعها (محلية/Supabase)، مدة بقائها، وتاريخ بدايتها — ظاهرة في القائمة وفي الإعدادات |
| **نسيت كلمة المرور** | إرسال رابط استعادة عبر البريد (في وضع Supabase) |
| **تأكيد قبل الحذف** | «خروج من كل الأجهزة» يطلب تأكيداً قبل إنهاء الجلسة |
| **إلغاء ربط Supabase** | زر «إلغاء الربط» في بطاقة Supabase يعيد التطبيق للتخزين المحلي دون حذف بياناتك |
| **لا تكرار في الحسابات** | تسجيل نفس البريد مرتين **يُرفض** برسالة واضحة + زر «لديّ حساب بالفعل» ينقلك لتبويب الدخول مع تعبئة البريد (حمايةً لبيانات حسابك القديم) |
| **انتقال سريع بين التبويبين** | زر داخل رسالة الخطأ ينقلك لتبويب «حساب جديد» أو «تسجيل الدخول» مع إبقاء البريد |

### 2. تنظيم اليوم والأسبوع والشهر
| العرض | التفاصيل |
|---|---|
| **لوحة التحكم** | ترحيب، إحصاءات اليوم، مركز الرسائل، جدول اليوم، مخطط الخطط والإنجاز الأسبوعي |
| **اليوم** | خط زمني ساعي، تصفية (الكل/عمل/شخصي)، قراءة الجدول بصوت، إضافة/تعديل/إنجاز سريع |
| **الأسبوع** | 7 أعمدة جانبية + مخطط توزيع الأحمال على الأيام + بداية أسبوع قابلة للاختيار (السبت افتراضياً) |
| **الشهر** | تقويم كامل مع مؤشرات المهام ونهايات الخطط + مخطط إنجاز الشهر |
| **كل المهام** | جدول بفلترة (بحث/النوع/الحالة) وترتيب (التاريخ/الوقت/الأولوية/الأحدث) |

### 3. فصل الحياة الخاصة عن العمل
كل مهمة وخطة لها **تصنيف**: `عمل` أو `شخصي`، مع ألوان مميزة وفلاتر فورية، وشرائح في التقويم
والجدول الزمني والأعمدة الأسبوعية.

### 4. التذكير في الوقت المحدّد
- محرّك تذكيرات يعمل كل 20 ثانية (وعند فتح التطبيق).
- **تنبيه صوتي** (نغمة) + **رسالة مرئية** على شكل بطاقة + **إشعار نظام** من المتصفح.
- مدة التذكير قبل الموعد قابلة للضبط (0–60 دقيقة).
- **الملخص الصباحي**: قراءة صوتية تلقائية لمهام اليوم عند الساعة 8:00.
- **تأجيل سريع** 10 دقائق بنقرة واحدة، و**تكرار** (يومي/أسبوعي/كل أسبوعين/شهري/سنوي) يولّد نسخة
  جديدة تلقائياً عند إنجاز المهمة.

### 5. القراءة الصوتية (TTS)
- يعتمد على **Web Speech API** مع اختيار يدوي للصوت، التحكم بالسرعة والنبرة.
- **تحويل الأرقام والتواريخ والأوقات إلى نطق عربي طبيعي**:
  `14:30` ← «الساعة الثانية والنصف ظهراً»، `2026-10-22` ← «الخميس اثنان وعشرون أكتوبر».
- يُقرأ: مهمة معيّنة، جدول اليوم كاملاً، ملاحظة، خطة، أو رسالة من مركز الرسائل.

### 6. مخطط الخطط المتجددة
- خطة = اشتراك/عقد/شهادة لها **تاريخ بدء وتاريخ انتهاء** ودورة تجديد (شهري/ربع سنوي/سنوي/أسبوعي).
- **تجديد تلقائي**: عند تجاوز تاريخ الانتهاء يُمدَّد تلقائياً ويُسجَّل في تاريخ الخطة.
- بدون تجديد تلقائي تتحوّل الخطة إلى **منتهية** مع رسالة تنبيه.
- **مخطط زمني** (Canvas) يوضّح الأيام المتبقية لكل خطة + قائمة «تحتاج تجديداً قريباً» + نهايات الشهر.

### 7. الأرشفة وسلة المحذوفات (استرجاع المحذوف)
- **أرشفة**: زر «أرشفة» لكل مهمة/خطة/ملاحظة + زر **«أرشفة المهام المكتملة»** لإخفاء ما أنجزته دون فقده.
- **الحذف becomes reversible**: أي حذف ينقل العنصر إلى **سلة المحذوفات** وليس حذفاً نهائياً،
  مع زر **«تراجع»** في التنبيه نفسه، وزر **«استرجاع»** داخل السلة.
- تبويب **«الأرشيف والسلة»** في القائمة الجانبية يجمع:
  - *المؤرشفة*: إلغاء الأرشفة أو نقلها إلى السلة.
  - *سلة المحذوفات*: استرجاع أو **حذف نهائي**، مع زر **«إفراغ السلة»**.
- عدّاد على أيقونة القائمة يوضّح عدد العناصر المؤرشفة والمحذوفة.

### 8. التذكير عبر واتساب
- من **الإعدادات ← التذكير عبر واتساب**: رقمك، ومدة التذكير (الافتراضي **30 دقيقة** قبل الموعد).
- ثلاث طرق للإرسال:
  | الطريقة | المتطلبات | ملاحظة |
  |---|---|---|
  | **رابط محادثة** | لا شيء | زر «فتح واتساب» برسالة جاهزة (المتصفح يمنع الفتح التلقائي) |
  | **CallMeBot** | مفتاح من callmebot.com + رسالة `/allow` مرة واحدة | إرسال **تلقائي** من رقمك |
  | **Meta Cloud API** | حساب Meta Business + Phone Number ID + Access Token | إرسال تلقائي (يحتاج قوالب خارج نافذة 24 ساعة) |
- الرسالة تُرسل تلقائياً قبل الموعد بـ 30 دقيقة، وتحتوي العنوان والتاريخ والوقت والنوع.

### 9. تنبيه أولياء الأمور في مجموعة واتساب خاصة
- **تسجيل الدخول لأكثر من مستخدم**: قائمة «حسابات على هذا الجهاز» تظهر أعلى نموذج الدخول معتها بالصور الرمزية — نقرة على مستخدماً تعبّئ بريده وتنتقل لحقل كلمة المرور مباشرة، وزر «حساب آخر» ينقل لتبويب إنشاء الحساب.
- ترتيب القائمة حسب آخر تسجيل دخول، ويإتنا مع إطارات الجلسات: «تذكرني» (30 يوماً على الـ localStorage) أو جلسة عابرة (sessionStorage)، مع تنظيف الجلسات المنتهية تلقائياً والتراجع لجلسة التبويب إن انتهت الجلسة الدائمة.
من **الإعدادات ← قروب أولياء الأمور**:
- **رابط دعوة المجموعة** (انسخه من واتساب: المجموعة ← معلومات ← «إضافة إلى مجموعة») — أو **Group ID**
  للإرسال التلقائي عبر Meta Cloud API.
- **نص الترويسة** الذي يتصدر كل رسالة (مثل «تذكير من إدارة المدرسة»).
- **رسالة مخصصة**: اكتب نصاً وأرسله للمجموعة مباشرة.
- **ملخص اليوم**: رسالة جاهزة بمواعيد اليوم (أو اليوم المعروض) مرتّبة بالوقت.
- **الملخص اليومي التلقائي**: يرسل ملخص مواعيد اليوم للمجموعة كل صباح عند وقت تختاره.
- **تنبيه لعنصر محدّد**: زر «👥 تنبيه أولياء الأمور» بجانب كل مهمة أو خطة في الجدول والخط الزمني.

في وضع «رابط الدعوة» تُنسخ الرسالة **تلقائياً إلى الحافظة** ويُفتح واتساب (لأن المتصفحات تمنع الفتح
المباشر للمجموعات) — تلصقها وتُرسل. أما الإرسال **التلقائي** فيحتاج Meta Cloud API + Group ID.

> الرسائل تُبنى بالعربية مع تنسيق واتساب (`*عريض*`) وتحتوي: الترويسة + العنوان + التاريخ + الوقت
> + الملاحظات + خاتمة للتواصل مع الإدارة.

### 10. الربط بقاعدة بيانات Supabase
- **مكتبة Supabase الرسمية عبر CDN** (`@supabase/supabase-js@2`) مضافة في المكان المناسب من `index.html`؛ يستخدمها `js/sb.js` تلقائياً للمصادقة، مع بديل REST مباشر إذا تعذّر تحميلها (توافق 100%).
- من **الإعدادات ← الربط بقاعدة بيانات Supabase**: أدخل **Project URL** و **anon public key** واختبر الاتصال.
- عندها **تُستبدل دوال التخزين المحلي بدوال Supabase**: سحب كامل عند الدخول (مهام/خطط/ملاحظات/جهات اتصال/إعدادات) ورفع فوري مع كل إضافة/تعديل/حذف/أرشفة، مع بقاء نسخة محلية فورية للعمل دون اتصال.
- **تجديد الجلسة تلقائياً** عند انتهاء صلاحية الرمز (401) عبر refresh_token — بلا إعادة دخول كل ساعة.
- **رسائل خطأ عربية** لأنماط الشائعة: تعذّر الاتصال، بيانات غير صحيحة، بريد غير مفعّل، حد المحاولات، إلخ.
- **الربط جاهز تلقائياً في الموقع المنشور**: `supabase/config.js` يُنشر مع التطبيق ويحوي **مفتاح النشر العام فقط** (`sb_publishable_...`) — مفتاح مصمم ليكون علنياً لأن سياسات RLS تحمي البيانات. **المفتاح السرّي (`sb_secret_...`) لا يوضع فيه أبداً**، وسكربت النشر يرفض نشر أي ملف يحويه (خط دفاع تلقائي).
- **الإعداد الذاتي الذاتي الخاص بك**: انسخ `supabase/config.example.js` إلى `supabase/config.js` (محلياً) وضع مفاتيحك — فيُقرا تلقائياً عند الإقلاع.
- **عزل كامل**: سياسات **RLS** (`auth.uid() = user_id`) تحصر كل مستخدم في صفوفه.
- **كود SQL كامل جاهز للنسخ واللصق** في لوحة تحكم Supabase داخل `supabase/schema.sql` (جدول عناصر + ملفات تعريف + فهارس + دوال تحديث الوقت + السياسات).

### 11. قائمة المستخدمين (جهات الاتصال)
- **شاشة «قائمة المستخدمين»** في القائمة الجانبية: الاسم + **رقم واتساب** + **الدور** (ولي أمر / معلم / إدارة / طالب / أخرى) + ملاحظة + لون.
- بحث فوري بالاسم أو الرقم، وتصفية حسب الدور، مع عدّادات (إجمالي / أولياء الأمور / معلمون / إدارة).
- زر **«تنبيه واتساب»** لكل مستخدم: يبني رسالة بمواعيد اليوم باسمه ويرسلها (أو ينسخها للحافظة ويفتح واتساب).
- **اختيار المستقبِل**: في بطاقة «قروب أولياء الأمور» تختار «مجموعة الأولياء» أو أي مستخدم من القائمة.
- يمكن أرشفة/حذف المستخدمين (يدخلون سلة المحذوفات) واسترجاعهم.

### 13. إدخال التاريخ والوقت للاجتماعات والتنبيهات
- **نوع العنصر**: مهمة / **اجتماع أو موعد** / **تذكير** — بلون وشارة مميزة في كل الشاشات.
- **وقت البداية + وقت النهاية + المدة** في نموذج العنصر، ومترابطة تلقائياً:
  تغيير وقت البداية ← يُحسب وقت النهاية • تغيير المدة ← يُحدَّث وقت النهاية • تغيير وقت النهاية ← يُحدَّث المدة.
- **زر «اجتماع»** في شاشة اليوم يفتح النموذج جاهزاً (النوع=اجتماع، المدة=60 دقيقة، تاريخ اليوم المعروض).
- الخط الزمني يعرض الفترة كاملة: `17:00 – 18:30`، والتقويم يعرض المواعيد.
- **تحديد سريع للوقت**: أزرار «الآن» و«بعد 30 د» و«بعد ساعة» و«بعد ساعتين» و«مسح الوقت» — بنقرة واحدة تعبّئ وقت البداية (مقرباً لأقرب 5 دقائق) وتحسب وقت النهاية تلقائياً.
- **وقت التنبيه لكل عنصر**: اختر متى يصلك التذكير (الصوتي + واتساب): في الموعد / قبل 10 أو 15 أو 30 دقيقة / قبل ساعة / ساعتين / قبل يوم — أو «افتراضي» ليتبع الإعدادات العامة.

### 13. الحقول المخصصة (حسب الاحتياج)
- من **الإعدادات ← الحقول المخصصة** تعرّف أي حقل تحتاجه: `نص` / `رقم` / `تاريخ` / `وقت` /
  `اختيار من قائمة` / `نعم–لا`، مع خيار **«حقل مطلوب»** وكتابة خيارات القائمة.
- الحقول تظهر تلقائياً في **نموذج المهمة**، وتُحفظ قيمها لكل مهمة على حدة.
- تظهر القيم كـ**شارات** في جدول المهام وفي خط اليوم الزمني.
- **تصفية** المهام حسب قيمة أي حقل من قائمة منسدلة في شريط الأدوات.
- تعديل اسم/نوع الحقل أو حذفه (يُحذف وقيمه من كل المهام) بسطر واحد.

### 14. الملاحظات الخاصة
لوحة ملاحظات ملوّنة مع تثبيت، تعديل، حذف، وقراءة صوتية لكل ملاحظة أو للملاحظات كلها.

### 15. التصميم والتنقّل
- واجهة على نمط **شركات عالمية**: شبكة، بطاقة، أزرق مؤسسي، حواف دائرية، ظلال ناعمة، تباين عالٍ.
- **RTL أصيل**: `dir="rtl"` + خصائص CSS منطقية (`inset-inline`, `margin-inline`) تعمل بالانعكاس تلقائياً.
- **القائمة الجانبية**: تُطوى إلى أيقونات فقط على الشاشات الكبيرة (تُحفظ الحالة)، وتُفتح كقائمة منسدلة
  على الجوال مع إغلاق تلقائي عند اختيار صفحة أو النقر خارجها أو الضغط على Esc.
- **وضع داكن**، متجاوب بالكامل، خطوط Cairo العربية.
- أيقونات SVG داخلية (بدون مكتبات خارجية)، ورسم بيانية مكتوبة يدوياً على Canvas.

## بنية الملفات

```
secretary/
├─ index.html              # هيكل الواجهة (شاشات الدخول + التطبيق)
├─ manifest.webmanifest    # بيانات PWA
├─ sw.js                   # Service Worker للعمل دون اتصال
├─ css/styles.css          # نظام التصميم الكامل (متغيّرات CSS + RTL)
├─ js/
│  ├─ store.js             # التخزين + المصادقة + عزل البيانات + التجزئة + الأرشفة
│  ├─ sb.js                # عميل Supabase (GoTrue Auth + PostgREST) بدون SDK
│  ├─ notify.js            # قنوات الإرسال: واتساب (رابط / CallMeBot / Meta Cloud)
│  ├─ voice.js             # محرك النطق العربي + تحويل الأرقام/التواريخ
│  ├─ charts.js            # رسوم بيانية على Canvas (أعمدة، أشرطة، دونات، مساحات)
│  ├─ ui.js                # مكتبة الواجهة: إشعارات، نوافذ، تنسيقات
│  └─ app.js               # منطق التطبيق: الشاشات، المحرك، التذكيرات
├─ icons/                  # أيقونات PWA
├─ supabase/schema.sql     # جداول Supabase + سياسات RLS الجاهزة
└─ tools/
   ├─ make-icons.ps1       # توليد أيقونات PNG
   ├─ serve.ps1            # خادم ملفات محلي للتجربة
   └─ publish.ps1          # النشر على GitHub + تفعيل GitHub Pages
```

## نموذج البيانات (localStorage)

```
secretary:v1:users   → { "<userId>": { id, name, email, salt, hash, createdAt } }
secretary:v1:session → { userId, ts, remember }        (localStorage عند «تذكرني»)
       sessionStorage → نفس المفتاح                      (بدون «تذكرني»)
secretary:v1:u:<uid> → { ownerId, tasks[], plans[], notes[], messages[], settings{} }
secretary:v1:theme   → "light" | "dark"
secretary:v1:sb      → { url, key }              # إعداد Supabase
secretary:v1:sb_session → { access_token, user } # جلسة Supabase
```

- `task` : `{ id, title, notes, date, time, duration, category, priority, status, reminder, repeat, remindedAt, whatsappSentAt, archived, archivedAt, deletedAt, fields{} }`
- `plan` : `{ id, title, category, startDate, expiryDate, cycle, autoRenew, cost, note, status, history[], archived, deletedAt }`
- `note` : `{ id, title, text, color, pinned, createdAt, updatedAt, archived, deletedAt }`
- `settings.customFields` : `[{ id, name, type, options[], required }]` — تعريف الحقول المخصصة لكل مستخدم.
- `settings.whatsapp` : `{ enabled, phone, provider, lead, apikey, phoneNumberId, accessToken, target }`.
- `settings.parents` : `{ link, groupId, header, auto, time, category }` — قروب أولياء الأمور.

## ملاحظة أمنية مهمة

لأن التطبيق **بلا خادم**، فإن البيانات محفوظة على جهاز المتصفح فقط، والعزل بين المستخدمين
منفَّذ على مستوى مساحة التخزين (وغير «تشفيرياً» ضد من يملك وصولاً فعلياً لجهازك ولملف localStorage).
الاستخدام المقصود: **جهاز شخصي موثوق**، مع تفعيل قفل تلقائي، والاحتفاظ بنسخة احتياطية مصدَّرة.
لو احتجت حماية أقرب إلى بنية خادم/قاعدة بيانات، فالخطوة التالية هي نقل `store.js` إلى واجهة API خلفية
مع قاعدة بيانات حقيقية — بقية الشيفرة تعمل كما هي عبر طبقة التخزين.
